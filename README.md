# roomlog-Server

LiDAR로 방을 스캔하고 AI가 하자를 탐지해 수리 견적까지 연결하는 서비스의 백엔드입니다.

## 기술 스택

- Java 17 / Spring Boot 3.2.4
- MySQL + JPA
- Spring Security + JWT
- Cloudflare R2 (파일 저장)
- Kakao Local API (수리 업체 검색)

## 핵심 기능

**스캔 및 3D 재구성**
모바일에서 업로드한 LiDAR 파일(.zip)을 Cloudflare R2에 저장하고 AI 서버로 3D 재구성을 요청합니다. 처리 완료 후 콜백으로 결과를 수신하는 비동기 구조입니다.

**하자 탐지 및 비교 분석**
단일 방의 하자를 탐지하거나, 입주 전·퇴거 후 두 방의 스캔을 비교해 새로 생긴 하자만 추출합니다. 하자별 심각도와 수리 예상 비용을 함께 산정합니다.

**수리 업체 연결**
방 주소를 기반으로 Kakao Local API에서 주변 수리 업체를 검색하고, 선택한 업체로 견적 요청 이력을 저장합니다. 수리 완료 후 비용과 이력을 기록합니다.

## 백엔드 포인트

- AI 서버와 콜백 방식으로 통신해 긴 처리 시간을 비동기로 처리
- 집 → 방 → 스캔 → 분석 → 하자 계층 구조를 JPA로 관리, 상위 삭제 시 하위 데이터 일괄 삭제
- 사용자 API는 JWT, AI 콜백 API는 API Key로 분리 인증
- Swagger UI로 전체 API 문서 자동 생성
